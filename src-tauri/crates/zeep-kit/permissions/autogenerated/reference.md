## Default Permission

Default permissions for zeep-kit: prefs, keychain, and shell commands.

#### This default permission set includes the following:

- `allow-prefs-get`
- `allow-prefs-set`
- `allow-prefs-delete`
- `allow-prefs-get-all`
- `allow-keychain-get`
- `allow-keychain-set`
- `allow-keychain-delete`
- `allow-shell-which`
- `allow-shell-run`
- `allow-shell-run-stream`
